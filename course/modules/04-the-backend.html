The Outside World

Supabase, Netlify, and AI — the three external services that power She Is, and why each one is there.

Supabase: the invisible database

She Is doesn't own a server. Instead, it rents one from Supabase — a company that provides a ready-made database and authentication system via the internet.

Think of it like renting a storage unit instead of building a warehouse. You pay for the space; they handle the building, security, and plumbing.

assets/auth.js const sb = createClient( 'https://xagmrt...supabase.co', 'sb_publishable_Vryw...' ); async function saveTestResult( testName, resultType, resultData) { const user = await getUser(); if (!user) return null; await sb.from('test_results') .upsert({ user_id: user.id, ... }); }
Plain English
Connect to "our" Supabase project using its URL and a public key
The URL is the address of the database; the key is a badge that says "this is a She Is request"
saveTestResult is called after every test completion
First it checks: is the user logged in? If not, skip — no cloud save
.from('test_results') = "go to the table named test_results"
.upsert = "insert if new, update if already exists" (no duplicates)
🔑
Public key vs. secret key

The Supabase key in auth.js is marked sb_publishable_ — it's safe to be public. It only allows reading/writing data for the logged-in user. A secret key (like an AI API key) would give access to everything and must never appear in client-side code.

Magic link login: no passwords, ever

She Is uses "passwordless authentication." When you enter your email, Supabase sends you a link. Click the link → you're logged in. The link is your temporary password, delivered to your email.

1
You enter your email on login.html

The code calls sb.auth.signInWithOtp({ email }) — OTP stands for "one-time password"

2
Supabase sends you an email

The email contains a unique link valid for 1 hour. She Is has a custom email template for this (email-template-magic-link.html)

3
You click the link in the email

Your browser opens the app with special tokens in the URL. Supabase JS library detects them.

4
Session established — you're logged in

Supabase saves a session token in your browser. Every future request to the database includes this token automatically.

Netlify Functions: the AI middleman

She Is has two AI features: a narrative generator (turns your test results into a personal story) and a chat (ask questions about your results). Both use the Anthropic Claude API.

But calling the AI API directly from the browser would expose the secret API key. Solution: use a Netlify Function as a middleman.

Plain English
process.env.ANTHROPIC_API_KEY = read the secret key from Netlify's secure vault
The key is never written in the code — it's injected at runtime
client.messages.create sends the request to Claude
model: which version of Claude to use
max_tokens: 1024 means "stop after ~750 words to control cost"
messages: the actual prompt with the user's test results embedded
