# 微信云开发部署清单

源码位于 `miniapp/src`，微信开发者工具导入目录为 `miniapp/dist/dev/mp-weixin`（开发）或 `miniapp/dist/build/mp-weixin`（发布）。

## 1. 云环境

当前代码使用云环境 `cloud1-d4gkbgtzob1673d47`。如更换环境，只修改 `src/config.js` 中的 `CLOUD_ENV_ID`。

## 2. 数据库集合

在云开发控制台创建以下集合：

- `users`：匿名身份、用户主动选择的昵称和头像
- `assessments`：逐项测评答案与结果
- `activity`：读过的故事
- `portraits`：生成的内在画像缓存
- `stories`：文章元数据、正文、草稿与发布状态

这些集合全部通过云函数读写，权限应设置为“仅管理端可读写”。不要开放为所有用户可读。

## 3. 云函数

在微信开发者工具的 `cloudfunctions` 目录中，逐个上传并部署（云端安装依赖）：

- `login`
- `saveAssessment`
- `saveStoryRead`
- `saveReflection`
- `generatePortrait`
- `deleteUserData`
- `getStories`
- `adminStories`
- `adminStats`

`getStories` 只返回已发布文章，普通用户不能读取草稿。`adminStories` 和 `adminStats` 必须配置云函数环境变量：

- `ADMIN_OPENIDS`：允许进入后台的微信 OpenID；多个账号用英文逗号分隔

三个管理员相关动作都在云函数中再次核对 OpenID。不要只依靠小程序里隐藏入口，也不要把管理员 OpenID 写进前端源码。

为 `generatePortrait` 配置云函数环境变量 `DEEPSEEK_API_KEY`。密钥不得写入源码、`config.js` 或小程序后台的普通配置中。默认模型为 `deepseek-v4-flash`；如需切换，可额外设置 `DEEPSEEK_MODEL`。该函数只向 DeepSeek 发送测评名称、结果标签和分数，不发送昵称、OpenID 或原始答案。

## 4. 隐私配置

在小程序后台根据实际功能填写《小程序用户隐私保护指引》，至少核对：

- 微信昵称、头像（用户主动选择）
- 保存结果图片到系统相册
- 匿名身份、测评答案、阅读记录的云端存储用途
- 数据删除方式：个人中心 → 隐私与数据 → 删除我的全部云端数据

正式提审前，用体验版分别验证首次授权、拒绝授权、再次授权和删除数据。

## 5. 合法域名与资源

将 `https://sheisapp-audio-2026.oss-cn-beijing.aliyuncs.com` 配置为小程序所需的合法资源域名，并真机验证封面、背景音乐和朗读音频。开发工具中的 `urlCheck: false` 只用于开发，不替代后台域名配置。

## 6. 第一次启用内容后台

1. 部署 `getStories`、`adminStories`、`adminStats`，三者都选择“云端安装依赖”。
2. 在 `adminStories` 和 `adminStats` 的环境变量中填写相同的 `ADMIN_OPENIDS`。
3. 创建 `stories` 集合，并设置为“仅管理端可读写”。小程序不会直连集合，所有读取和发布都经过云函数。
4. 重新编译小程序，以管理员微信登录。
5. 打开“我的”，进入“内容与数据后台”。
6. 第一次点击“首次导入现有 11 篇”，把安装包里的旧文章复制到云端。

首次导入完成后，旧文章仍保留在安装包里作为断网兜底；云端同编号文章优先展示。

## 7. 以后新增或修改文章

1. 封面、背景音乐和朗读音频先上传到 OSS，并取得 `https://` 地址。
2. 打开小程序“我的” → “内容与数据后台”。
3. 点击“新文章”，填写编号、标题、摘要、素材地址和正文。
4. 先“保存草稿”，在正文预览里检查段落。
5. 点击“发布文章”。用户刷新故事页后即可看到，不需要重新提交小程序版本。

修改已发布文章时，点进文章重新保存即可；点击“下架文章”后，普通用户将无法再打开，但正文会保留在后台。只有新增页面、播放器能力或其他程序功能时，才需要重新打包和提交微信审核。

## 8. 用户数据管理

“我的”页面提供两种用户自助操作：

- “复制我的数据”：导出这台设备上的个人资料、测评、阅读、内在回答和画像，不含 OpenID。
- “清除这台设备上的记录”：只清本机，不删除云端副本。
- “删除我的全部云端数据”：删除用户在 `users`、`assessments`、`activity`、`portraits` 的记录和云端头像。

管理员后台只汇总已经主动开启跨设备同步的用户，显示同步用户数、近 7 天活跃、测评完成量、故事读者数和内在回答数量。它不会返回昵称、OpenID、原始测评答案或内在回答正文，也不把未登录用户误计为“全部用户”。
